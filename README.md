# Rule-Based Chatbot

## About the Project
This project is a simple rule-based chatbot developed using Python. It interacts with users by identifying predefined keywords and providing appropriate responses.

The chatbot uses basic conditional statements to handle greetings, common questions, and unknown inputs.

## Features
- Responds to common greetings such as Hello, Hi, and Hey.
- Answers basic questions about itself.
- Provides predefined responses to Python-related questions.
- Handles unknown messages with a fallback response.
- Supports continuous conversations.
- Allows users to exit the chatbot using Bye or Exit.

## Technologies Used
- Python 3
- Conditional Statements (if-elif-else)
- While Loop
- String Operations

## How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder.

3. Run the Python file:

   ```bash
   python RuleBasedChatBot.py
   ```

## How It Works
The chatbot takes user input and converts it into lowercase. It then checks for predefined keywords using if-elif-else conditions and displays the corresponding response.

If no matching keyword is found, it displays a default fallback response.
